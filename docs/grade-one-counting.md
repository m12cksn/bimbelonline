# Counting visual increment

Adds a tap-to-mark counting aid for explicitly recognized repeated-object prompts, including the first live Grade 1 apple question. Objects retain their source identity; no automatic total or answer key is shown. Existing images take precedence. Unsupported stories, mixed icons, arithmetic and quantities over 20 are rejected. Original answer submission/grading remains unchanged. Preview example: /preview/grade-one.

Verification: TypeScript noEmit passed before preview sample addition; 192 Jest tests passed; targeted lint passed. Browser, keyboard interaction and final preview rendering remain unverified. Full 240-question conversion is incomplete; no production/database writes performed.
