# Admin all-question preview

On the regular material practice screen, admins can toggle Preview semua soal to render the complete regular-practice catalog for that material on one page using the existing question UI. Students and guests retain their existing pagination. Preview hides submission and guards submitPage; no grading request or progress write is initiated in this mode. Existing authenticated content endpoint and public projections are unchanged; no answer keys are loaded for preview.

Verification: source inspection only. Typecheck, browser testing and role regression testing remain pending; local checkout/dependencies are unavailable following workspace maintenance. Not deployed.
