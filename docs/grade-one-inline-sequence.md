# Inline train answers

Grade 1 regular practice: recognized essay number sequences use a controlled input in the unknown wagon and hide the duplicate textarea. Multipart sequence items use the existing per-item serialized answers in the same way. MCQ, image-backed prompts and unrecognized text retain existing controls. No answer is computed or embedded; grading stays server-side. Disabled state locks the inline input after submission; existing reset clears the shared answer state. Standard text input with numeric keyboard hint preserves existing server validation.

Validation: TypeScript noEmit and targeted component ESLint pass; 285 existing Jest tests pass. These do not verify new DOM interactions. Preview build and browser/keyboard/mobile submission testing pending. Not deployed. Corner radii reduced for train scene and wagons.
